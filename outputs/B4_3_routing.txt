Hi Mike,

Great question! I'm happy to walk you through our data export capabilities.

**How to Export Your Project Data:**

1. **Single Project Export:**
   - Navigate to your project dashboard
   - Click the "Actions" menu (three dots) in the top right
   - Select "Export to Excel"
   - Choose your preferred format (XLSX or CSV)
   - Click "Download"

2. **Bulk Export (Multiple Projects):**
   - Go to the main Projects page
   - Use checkboxes to select the projects you want to export
   - Click the "Bulk Actions" button at the top
   - Select "Export Selected Projects"
   - Your file will be compiled and downloaded automatically

**Pro Tips:**
- You can customize which fields to include by clicking "Export Options" before downloading
- Scheduled exports can be set up under Settings > Automation if you need regular exports
- Large datasets (1000+ records) will be emailed to you rather than downloaded directly

**Relevant Documentation:**
- [Complete Export Guide](link-to-docs/exporting-data)
- [Customizing Export Fields](link-to-docs/export-customization)
- [Setting Up Automated Exports](link-to-docs/automation)

**Related Features You Might Find Helpful:**
- **Data Templates**: Save your export configurations for repeated use
- **API Access**: For programmatic exports if you need integration with other tools
- **Report Builder**: Create formatted reports with charts before exporting
